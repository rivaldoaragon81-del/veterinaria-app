# Proyecto Veterinaria App

## Descripción

Aplicación desarrollada en Angular para gestionar el proceso de atención de una clínica veterinaria.

## Funcionalidades

- Registro de mascotas
- Registro de propietarios
- Agenda de citas
- Historial médico
- Validaciones con Reactive Forms
- Pipe personalizado para estados
- Directiva personalizada para resaltar citas

## Tecnologías

- Angular
- TypeScript
- HTML
- CSS

## Instalación

```bash
npm install
```

## Ejecución

```bash
ng serve
```
